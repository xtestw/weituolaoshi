# 次元委托 V1 视觉规则

适用于 C 端、Coser 端及所有系统页面。保留现有浅色界面与蓝紫主色、粉色交易强调色；不改变业务入口与页面结构。

## 文字层级

| 层级 | 用途 | 字号 / 字重 | 颜色 |
| --- | --- | --- | --- |
| 页面标题 | 顶栏、详情主标题、结果页主状态 | 38rpx / 800 | `--color-text` |
| 区块标题 | 卡片分组标题、弹层标题 | 34rpx / 750 | `--color-text` |
| 卡片标题 | 委托标题、消息发送者、入口主文案 | 30rpx / 700 | `--color-text` |
| 正文 | 说明、列表主值、表单输入 | 28rpx / 400–650 | `--color-text` |
| 元信息 | 时间、地点、次要状态、操作链接 | 25rpx / 500–700 | `--color-muted` 或 `--color-primary-ink` |
| 注释 | 辅助说明、计数与紧凑标签 | 23rpx / 400–600 | `--color-muted` |

页面和区块标题使用 1.25–1.3 行高；正文与说明使用 1.4–1.5 行高。价格可加粗，但单位使用元信息字号。密集日历、角标等组件可用 21–22rpx，避免用于长段说明。

## 颜色与状态

- 主文本 `--color-text`，次级文本 `--color-muted`，浅次级文本 `--color-muted-soft`。
- 可点击链接与选中态使用 `--color-primary-ink`；实色主按钮使用 `--color-primary`。
- 价格、发布入口与交易 CTA 使用 `--color-cta`；粉色文字使用 `--color-cta-ink`。
- 成功、可约使用 `--color-success`；风险、错误使用 `--color-danger`。状态同时保留文字，不能只靠颜色表达。
- 页面背景 `--color-bg`，内容卡片为白色，边框 `--color-border`；柔和选中底色用对应的 `*-soft` token。

## 图标与控件

- 导航与操作图标采用同一套线框语言：主图标约 42–44rpx、4rpx 描边、圆角端点；发布是唯一的实色强调图标。
- 图标旁已有文字时，图标作为装饰隐藏于无障碍树；单独的图标按钮必须有清楚的 `aria-label`。
- 小图标不缩小可点击区；主导航和弹层操作保持至少 88rpx 高。
- 不使用 emoji 作为功能图标。头像中的单字是头像占位符，不代表功能。

## 实施范围

全局 token 在 `app.wxss`；主底栏在 `custom-tab-bar`；Coser 独立底栏在 `components/b-tabbar`。页面 CSS 使用上述 token，业务特殊的插画、渐变和封面色可保留局部颜色。
