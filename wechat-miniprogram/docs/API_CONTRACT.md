# V1 服务端状态机与接口约束

## 订单状态

```text
draft
  -> awaiting_payment
  -> paid_pending_coser
  -> awaiting_service
  -> customer_completed / coser_completed
  -> completed
  -> settlement_pending
  -> settled

任一允许状态
  -> cancel_requested
  -> cancel_agreed / dispute_review
  -> refund_pending / compensation_pending
  -> cancelled
```

所有状态变化必须由服务端校验当前状态与操作者角色，写入不可修改的事件日志，并使用幂等键防止支付回调、重复点击或网络重试造成重复扣款、重复退款和重复结算。

## 全女平台与履约责任

- 首次进入提示以服务端生成的设备标识 DID 记录展示状态，每个 DID 仅展示一次；小程序本地演示使用本地生成的 DID，清理数据或换设备后会再次出现。
- 未实名、男性及未满18岁可浏览；服务端在创建订单、发起支付、发布帖子时重复校验实名结论、年龄和女性身份。前端弹窗只用于解释限制，不能替代服务端拦截。
- 取消或未履约原因提交后先生成 `pending` 审核记录。管理员审核后写入不可改的决定、证据、审核人和时间。只有 `approved + decision=coser + fulfillmentIncomplete=true` 才计入Coser首页，每个订单最多一次；撤销决定后需重算。
- 生产接口需要 `POST /v1/order-responsibility-cases`、`GET /v1/admin/order-responsibility-cases`、`POST /v1/admin/order-responsibility-cases/:id/decisions` 和 `GET /v1/cosers/me/incomplete-count`。前端演示版仅保存待审核记录，不提供管理员审核操作。

## 现场签到与评分

- 仅已付款、Coser已确认且未取消的订单可生成履约码。服务端对每笔订单生成一次固定的4位码并向C端展示；B端不得直接读取明文。服务端保存摘要、限制错误尝试次数，签到成功或订单取消后立即作废，不提供换码入口。
- B端提交4位码、实时定位及至少一张现场照片。服务端核验订单、码、地理位置、时间与照片审核结果后，原子地将订单改为履约中；失败不得改变状态。照片须上传到受控存储并按隐私期限清理。
- 客户在完成订单后可对该笔交易评分一次；Coser平均分按所有已评分交易计算，未评分交易不进入分母。评分变更与申诉须保留审计记录。
- 紧急联系采用用户预设号码，点击悬浮入口后先确认，再调起系统拨号；平台不能假定系统拨号成功或已经联系上联系人。

## 下单资格

服务端创建订单前必须重新校验：

1. 用户与Coser均实名认证、年满18周岁且核验结论为女性；其他用户可浏览但不能交易。
2. 接口只返回允许/拒绝，不返回对方证件字段。
3. Coser帖子已审核并处于可交易状态。
4. 预约区间不跨自然日、不属于过夜时段，并包含在Coser可接单档期内。
5. 对应档期无其他订单锁；创建待支付订单时使用短期锁，支付成功后改为履约锁。
6. POI属于平台允许的公共场所分类，且预约时段处于营业时间。
7. 距履约不足24小时的订单存在双方聊天确认记录。
8. Coser责任未完成履约记录应由管理员审核确认后计数，审核中与无责记录不计入；同一订单仅计一次。

## 身份数据返回模型

```json
{
  "verificationId": "iv_xxx",
  "status": "verified",
  "adult": true,
  "legalGender": "F",
  "maskedDocumentNumber": "310***********182",
  "verifiedAt": "2026-11-10T12:00:00+08:00"
}
```

前端永远不接收身份证原图或完整证件号。完整数据只允许由受限服务处理；业务库保存供应商凭证、不可逆摘要和最少必要结论。

## 金额模型

订单金额必须由服务端计算并返回签名报价，前端不得提交最终应付金额：

```json
{
  "quoteId": "qt_xxx",
  "serviceAmount": 56400,
  "customerPlatformFee": 0,
  "protectionFee": 2800,
  "payableAmount": 56400,
  "currency": "CNY",
  "expiresAt": "2026-11-10T12:10:00+08:00"
}
```

金额单位统一使用分，禁止浮点数。V1用户侧平台抽佣为0；Coser侧的平台安全保障费用为成交金额的5%，在报价编辑页展示每小时预计费用与实收，在结算账单中按整单成交金额计算并扣除。服务端应明确费用对应的服务、退款规则和逐单四舍五入到分的口径。

用户通过微信支付付款；履约完成并满足结算条件后，平台按微信支付商户侧的合规出款流程结算至Coser微信账户。产品不设置站内钱包、余额、提现或保证金入口。退款原路退回，责任赔付应有独立账单和服务端记录。前端演示版仅模拟状态，不发起真实资金交易。
